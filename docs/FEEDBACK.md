## What We Heard (Themes)

1. **Flow clarity:** 16 responses requested clearer onboarding, workflow explanations, examples, or next-step guidance.
2. **Trust and privacy:** testers valued selective disclosure and asked for clearer visibility rules, sensitive-data warnings, status, and validity.
3. **Submission confidence:** testers requested input examples, a pre-submit review, stronger success feedback, and an explicit next action.
4. **Mobile usability:** small-screen input and navigation spacing needed improvement.
5. **Future enhancements:** share links, reusable templates, history, undo, optional roles, and faster results are useful roadmap items.

## Deferred Roadmap

- Temporary share links and saved disclosure templates
- Searchable activity history
- Undo/remove flow for reversible off-chain records
- Failed-verification demo fixture backed by real Preprod state
- Performance instrumentation for proof and indexer wait time

These items need product or protocol work beyond the top feedback fixes selected for Level 5.
